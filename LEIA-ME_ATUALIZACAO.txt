AUTO BRILHO WEB - CONCILIAÇÃO FINANCEIRA E NORMALIZAÇÃO DE DESPESAS v16

IMPORTANTE
- Este pacote NÃO contém config.js. Preserve o config.js já publicado no GitHub Pages.
- Não apague nem substitua o projeto Supabase e NÃO execute SQL para esta atualização.
- A atualização não exclui registros existentes.

CORREÇÕES v16
- Mantém a correção v15: serviços históricos importados marcados como Concluído e Recebido geram o recebimento vinculado que estiver faltando, usando a data do serviço conforme confirmado.
- Mantém a prevenção de pagamentos duplicados por vínculo com o serviço.
- Corrige a interpretação da situação das despesas na importação Excel: Pago/Paga, Quitado/Quitada e Liquidado/Liquidada são reconhecidos como Pago.
- Situações não reconhecidas são mantidas como Em aberto. O sistema não presume que uma despesa foi quitada.
- Despesas são gravadas diretamente na tabela de despesas, que já alimenta Contas a pagar, Movimento financeiro, dashboards e relatórios. Diferentemente dos serviços, não precisam gerar um segundo lançamento em outra tabela.
- O cache PWA foi atualizado para v16.

DATAS E CONTABILIZAÇÃO
- Despesa paga: informe a Data do pagamento para que seja considerada no mês correto nos relatórios e indicadores.
- Despesa em aberto: informe a Data de vencimento; ela permanece em Contas a pagar e não entra no total de despesas pagas.
- O aplicativo não inventa uma data de pagamento quando ela não foi informada.

COMO ATUALIZAR PELO CELULAR
1. Baixe e extraia este ZIP.
2. No GitHub, abra o repositório auto-brilho-web e substitua os arquivos correspondentes, mantendo a mesma estrutura.
3. NÃO substitua nem apague config.js. Ele não está incluído neste pacote.
4. Aguarde a publicação do GitHub Pages.
5. Feche completamente o Auto Brilho e abra novamente. Entre com seu acesso normal.
6. Confira Receitas e pagamentos, Despesas, Contas a pagar, Dashboards e Relatórios.

SEGURANÇA
- Faça um backup JSON antes da atualização, como precaução normal.
- Não é necessário reimportar clientes ou serviços já importados.
- Não execute SQL nem apague dados do Supabase.
