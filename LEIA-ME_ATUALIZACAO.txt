AUTO BRILHO — VERSÃO 30 — REDESIGN VISUAL

Esta atualização parte do pacote funcional v28 e reorganiza a interface para se aproximar da referência visual aprovada:
- cabeçalho preto com destaque vermelho;
- menu lateral escuro com seção ativa em vermelho;
- área de trabalho clara, com cartões brancos;
- formulários, tabelas, indicadores e gráficos com aparência mais limpa;
- adaptação para celular, mantendo navegação lateral compacta.

IMPORTANTE
1. Faça backup dos arquivos atuais do GitHub antes de substituir.
2. O arquivo config.js NÃO está incluído. Preserve o config.js já existente no repositório, pois contém a configuração de conexão com o Supabase.
3. O app.js foi mantido a partir da v28, sem alteração de regras de negócio ou estrutura dos dados.
4. Substitua os arquivos do pacote mantendo a mesma estrutura de pastas.
5. Após publicar, abra o aplicativo e atualize a página. Se a versão antiga continuar em cache, feche e reabra o navegador ou use a opção de atualizar quando aparecer.

VALIDAÇÃO TÉCNICA
- app.js: verificação de sintaxe JavaScript aprovada (node --check).
- sw.js: verificação de sintaxe JavaScript aprovada (node --check).

A aparência deve ser validada em desktop e celular antes de considerar esta versão definitiva. A versão v28 deve ser mantida como cópia de segurança até a conclusão dos testes.
